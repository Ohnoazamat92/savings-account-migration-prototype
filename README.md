# Переход на новый накопительный счёт

[Открыть интерактивный прототип](https://ohnoazamat92.github.io/savings-account-migration-prototype/)

Восемь вариантов для обсуждения: отдельный экран, боттомшит, открытие с отдельным переводом, последовательный переход, массовый выбор и разговорный сценарий по одному вопросу, его минимальный вариант и общий план действий для одного счёта.

Выберите вариант A–H. Переключатели позволяют проверить нулевой остаток, потерю ответа, частичный успех массового перехода, наличие автопополнения и ошибку переноса его настроек. Это демонстрация; банковских операций нет, данные вымышлены.

Прототип находится в `prototypes/account-migration/index.html`. Можно открыть файл напрямую в браузере. Установка зависимостей не требуется.

[Результаты проверки и обоснование выбора](prototypes/account-migration/Проверка%20и%20выбор.md)

Публикация: GitHub Pages из корня ветки `main`.

Вариант F: [открыть напрямую](https://ohnoazamat92.github.io/savings-account-migration-prototype/prototypes/account-migration/?variant=F). Перенос денег означает весь остаток со старого счёта. Если отказаться, новый остаётся пустым, а старый — открытым. На итоговом экране можно изменить ответы.

Проверка логики без зависимостей: `node prototypes/account-migration/check-conversation.cjs`.

Вариант G: [минимальный](https://ohnoazamat92.github.io/savings-account-migration-prototype/prototypes/account-migration/?variant=G&v=minimal-g-2). Сразу открывает первый вопрос. Без сквозного заголовка, номеров шагов, имитации статус-бара; данные собраны на серых подложках, логика общая с F.

Вариант H: [общий экран одного счёта](https://ohnoazamat92.github.io/savings-account-migration-prototype/prototypes/account-migration/?variant=H&v=overview-h-1). Сумма из приложенного макета — 52 326 ₽. Подробности перевода, автопополнения и закрытия возвращают на общий экран. Операция запускается один раз после согласия. Предложение доступно по стрелке назад.
