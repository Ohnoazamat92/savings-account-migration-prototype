# Переход на новый накопительный счёт

[Открыть интерактивный прототип](https://ohnoazamat92.github.io/savings-account-migration-prototype/)

Пять вариантов для обсуждения: отдельный экран, боттомшит, открытие с отдельным переводом, последовательный переход и массовый выбор.

Выберите вариант A–E. Переключатели позволяют проверить нулевой остаток, потерю ответа и частичный успех массового перехода. Это демонстрация; банковских операций нет, данные вымышлены.

Прототип находится в `prototypes/account-migration/index.html`. Можно открыть файл напрямую в браузере. Установка зависимостей не требуется.

[Результаты проверки и обоснование выбора](prototypes/account-migration/Проверка%20и%20выбор.md)
